# Deployment requirements for Streamlit Community Cloud.
# Streamlit Cloud looks for requirements.txt next to the entrypoint script
# (app/streamlit_app.py's parent folder) before falling back to the repo
# root, so this file is scoped to exactly what the deployed app needs —
# it intentionally leaves out the root requirements.txt's notebook/dev-only
# packages (jupyter, matplotlib-inline, scikit-learn, etc.) and keeps
# versions unpinned so pip resolves one consistent, current set in a single
# pass (the local dev setup instead installs crewai in a second pass after
# pinned requirements, which a cloud build can't do).
streamlit
crewai
crewai-tools
langchain
langchain-community
langchain-groq
langgraph
groq
pandas
PyYAML
python-dotenv
matplotlib
SQLAlchemy
